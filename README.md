# Marginalia

A mobile-first book tracker in Spanish and English. Log pages, keep a library, see your reading journal, goals and stats.

It is a single static page (`index.html`). Each person's library is saved in their own browser, so nothing is shared or synced between devices.

## Run it

Open `index.html` in a browser, or host the folder on any static host.

## Publish with GitHub Pages

Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
